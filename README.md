# Gobsmacked

一个完全本地、以时间为索引的个人记录系统。它将文字、图片、录音、标签、地点、日期标注和纪念星位事件收纳为版本化的 `.gob` 记录，并提供日 / 年编辑、月历与内层时间轴查阅。

## 已有能力

- 首次身份建立后，启动密钥与历史密钥分别设置和验证；历史密钥禁止与启动密钥相同。主页面可将本机加入信任名单，下次仍显示身份界面，但无需填写启动密钥即可进入；历史记录始终要求独立验证。
- 今日记录 / 本年总结切换、曜日默认标签、约 0.85 秒防抖自动保存及 `Ctrl+S`；当下界面不允许切换到过去日期。
- 中文 / English 即时切换，中文界面采用简练的功能性表述。
- 图片和录音都在填写标签后按光标位置嵌入正文，只显示可点击标签；录音使用标签上方的圆形播放器，图片先显示小预览，再点击查看大图。
- 只读月历、唯一标注 / 跨年标注；标注文字直接显示在对应日期格内。
- 纯 Canvas 计算生成的银河尘埃带、星团、多层恒星、彩色星云与全息地球，不使用背景贴图或地图贴图。
- 1 + 2 + 2 + 7 的纪念星位；从页面顶部的短横柄向下拖拽即可拉开当前页面并显露星空，正文滚动不再触发天幕。
- 二次验证后的只读过去查阅；纵向测微式时轨固定中心读数线，滚动或拖动日期套筒经过中心完成选择，以年为主刻度、实际记录日为细分刻度。
- 历史时轨采用稳定后加载：滚动期间只更新中心日期，停止或松开后才读取一次正文；被遮挡的星空画布暂停重绘。
- 独立加密档案支持虚拟目录浏览、筛选、加密导入、临时解密打开和按需提取；文件名、目录结构和文件本体均不写入项目目录。
- 旧 TXT 日记分段导入；“导出内容”生成完全解密的记录、媒体和资料目录，“迁移备份”则复制可运行系统、加密档案与恢复所需的用户数据。
- Windows 程序文件夹与 `Gobsmacked.exe` 启动器构建配置。

详细范围和阶段状态见 [工程工作清单](docs/WORKLIST.md)，记录格式见 [Gobsmacked Record 规范](docs/FORMAT.md)。

## 开发运行

需要 Node.js 22 或更高版本。

```powershell
npm install
npm test
npm start
```

## 生成 Windows 程序文件夹

```powershell
npm run pack
```

产物直接写入系统目录。双击 `E:\Gobsmacked\System\Gobsmacked.exe` 启动；`System` 中的 `resources`、`locales`、DLL 与数据文件都是运行所需组件。它们是本地运行产物，不提交到源码仓库。

## 资料保存位置

开发版和安装版默认使用 Electron 的系统用户数据目录。Windows 通常位于：

```text
%APPDATA%\Gobsmacked\vault
```

真实位置由 Electron 在运行时确定。它只保存结构化记录、记录内图片和录音、日期标注及天幕事件。

总目录只分为系统与密文档案两部分：

```text
E:\Gobsmacked\
  System\
    Gobsmacked.exe
  Archive\
    archive.info
    manifest.gobseal
    objects\<加密对象>.gse
```

清单和对象采用 AES-256-GCM 加密，密文目录不暴露原文件名。档案密钥由历史密匙与固定上下文经 scrypt 派生，历史密匙和派生密钥均不落盘、不写入项目。程序只在“历史记录 → 资料”通过二次验证后在内存中解锁清单；打开文件时写入会话临时目录，退出内层或关闭程序时清理。

## 备份与安全边界

- “导出内容”将结构化记录和媒体写入 `Records`，并将大文件解密到 `Files`；导出位置必须有足够空间，且导出结果需要单独保护。
- “迁移备份”生成 `System` + `Archive` + `UserData` 备份；大文件档案保持 AES-256-GCM 密文，恢复后仍需原历史密匙。
- “提取”只解密当前选中的资料或目录到指定位置，保留密文原件；导入同名文件会生成不冲突的新名称并立即加密。
- 内容导出和迁移备份都先写入唯一的 `.partial` 目录，只有全部文件完成后才改为正式目录名。
- 档案使用 AES-256-GCM；256 位密钥由“历史密匙 + `中国河南省焦作市|LAT=35.25|LON=113.23|0722`”经 scrypt（N=131072, r=8, p=1）派生。上下文不是秘密，安全性依赖历史密匙的强度；仍建议启用 BitLocker。
- 迁移备份不会删除当前系统；备份完成后应检查 `migration.json` 和 `RESTORE.txt` 存在。
- 地点窗口仅保留文字输入、保存和定位。直接保存完全离线；主动定位时才会将地点文字发送给 OpenStreetMap Nominatim，结果保存在本地缓存。

## 源码仓库边界

Git 仓库只保存 `src/`、`test/`、通用 `scripts/`、工程文档和依赖清单。`.gob` 记录、媒体、密文对象、密钥、安全配置、导入报告、运行时文件和个人文档均被忽略。提交前应运行 `git status --ignored`，确认没有私人资料进入暂存区。
