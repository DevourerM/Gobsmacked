# Gobsmacked：工程工作清单

> 文档状态：V0.1 基线。标记说明：`[x]` 已实现，`[~]` 已建立首版能力、仍可深化，`[ ]` 后续阶段。

## 1. 产品边界与原则

- [x] 以“日记录 / 年记录”作为两类一等资料，使用统一的数据模型和独立索引。
- [x] 原始资料完成逐文件加密封存；结构化记录写入系统用户数据目录，大文件密文保存在程序同级的独立仓库。
- [x] 离线优先，不上传正文、媒体、标签、口令或地点。
- [x] 所有视觉背景、星空、星尘、星云、地球和纪念星位均由 Canvas/CSS 计算生成，不依赖贴图。
- [x] Windows 桌面程序，提供开发启动与“程序文件夹 + Gobsmacked.exe 启动器”的构建配置。
- [~] 无障碍：键盘焦点、语义按钮、对比度及“减少动态效果”已覆盖基础场景。
- [ ] 国际化、屏幕阅读器专项验收、高对比主题。

## 2. 独特记录格式（Gobsmacked Record / `.gob`）

- [x] 版本化文档头：`schema`、`version`、`id`、`kind`、`date`、`createdAt`、`updatedAt`。
- [x] 块式内容模型：段落块、图片块、音频块；后续可兼容视频、文件、引用和手写块。
- [x] 元数据：标题、标签、地点坐标/显示名、摘要。
- [x] 媒体导入资料库后由资源 ID 引用，避免外部文件被移动后失效。
- [x] 图片和录音以正文内标签引用；图片使用小预览到全屏查看的两段交互，录音使用圆形进度播放器。
- [x] 原子写入（临时文件完成后替换），降低断电或崩溃导致的损坏风险。
- [x] Schema 版本校验及未知字段兼容策略。
- [ ] 单文档自包含封装、媒体去重（SHA-256）、历史版本与冲突合并。

## 3. 身份认证与隐私

- [x] 首次启动创建身份名与访问口令。
- [x] 启动密钥与历史密钥独立设置、独立加盐并使用 scrypt 派生摘要保存；禁止两者相同。
- [x] 应用入口验证；错误提示不泄露内部认证数据。
- [x] 本机信任名单：主页面可启用或取消；受信任设备下次在身份页直接进入，但不会解锁历史资料。
- [x] 设备信任使用随机本机令牌，安全配置只保存令牌哈希，信任凭证不写入记录资料库。
- [x] 进入“过去”内层时再次验证。
- [x] 导出入口仅存在于验证后的内层。
- [~] 内层会话只在当前应用运行期有效，关闭内层即失效。
- [ ] 自动锁定、失败节流、安全问题恢复、Windows Hello / 硬件密钥。
- [~] 大文件资料库已使用 AES-256-GCM 整体加密并在退出内层时清理内存密钥；历史密钥派生换钥与威胁模型审计继续完善。

## 4. 今日记录与编辑器

- [x] 启动后默认进入今天的日记录。
- [x] 日 / 年模式切换；年模式自动切换到当前年份总结。
- [x] 当下界面只允许编辑今天或本年度；日历仅展示状态和标注文字，过去内容只能在内层查阅。
- [x] 中文 / English 界面切换及简练的功能性文案。
- [x] 标题、正文、标签、地点统一自动保存，并显示保存状态。
- [x] 默认生成当天的日文曜日标签；用户可增加和删除任意标签。
- [x] 图片导入后填写标签并插入光标位置；图片与录音标签都可随正文保存和删除。
- [x] 音频入口直接调用麦克风录音；停止后填写标签，并按光标位置插入正文中的可点击录音引用；试听与播放使用圆形进度环。
- [x] 图片标签打开无背景遮罩的小预览，再点击进入全屏；录音标签上方打开无背景虚化的小播放器。
- [x] 空记录、载入失败和媒体失效的明确状态。
- [ ] 富文本样式（标题层级、列表、引用）、Markdown 粘贴与拖拽排序。
- [ ] 全文搜索、标签建议、关联记录、日记模板与写作统计。

## 5. 日历与日期标注

- [x] 月历上月 / 下月 / 回到今天。
- [x] 点击日期加载并编辑对应日记录。
- [x] 有记录日期、被选日期、今天、标注日期采用不同视觉状态。
- [x] 标注支持“仅此日期”与“每年此日”两种作用域。
- [x] 标注可添加、查看和删除；跨年标注在每年同月同日显示。
- [x] 标注文字直接显示在日期格内，完整内容可通过悬停查看。
- [ ] 农历、节气、多条标注排序、颜色/提醒、自定义纪念日图标。

## 6. 全息地点地球

- [x] 由经纬网与 Natural Earth 矢量边界生成全息地球，无地图贴图。
- [x] 显示陆地和国家轮廓，支持鼠标拖动三维旋转。
- [x] 可完全离线地只保存地点文字，界面不展示经纬度。
- [x] 用户主动点击时可通过 OpenStreetMap Nominatim 联网识别坐标，并将结果缓存到本地。
- [x] 已定位地点在地球上回显标记，切换记录时自动转向该地点。
- [ ] 离线地址数据库、地点收藏与轨迹回放。

## 7. 无言天幕与纪念星位

- [x] 日记正文优先滚动；到达底部并结束当前手势后，再次向下滚动才揭开天幕，避免与长日记翻阅冲突。
- [x] 固定层级：中心 1 颗、第一环 2 颗、第二环 2 颗、最外层 7 颗，共 12 颗星。
- [x] 星空内部不显示标题、说明、姓名或常驻状态文字；仅在悬停已点亮星位时显示点亮日期。
- [x] 银河尘埃带、暗尘、星团、星云、恒星色温与衍射光芒全部由 Canvas 程序生成。
- [x] 默认暗星；点击后永久点亮，不提供熄灭动作。
- [x] 每次触碰星位都将追忆时刻写入独立事件流，首次点亮日期另行保留。
- [ ] 星位历史的只读后台审计、资料库恢复工具与事件完整性校验。

## 8. 过去查阅

- [x] 当下页面不显示近期记录列表，过去内容统一从内层时间轴查阅。
- [x] 内层二次验证后进入只读的过去查阅。
- [x] 游戏式统一时轨：年为大刻度，实际存在的日记录为小刻度；没有日记录时仅显示年刻度。
- [x] 时间轴预览标题、正文、图片、音频、标签和地点。
- [x] 过去页采用紧凑年份轨道、记录日节点、选中日期光标和文档式只读预览；单年份数据自动居中。
- [x] 从历史预览跳回主编辑器继续编辑。
- [ ] 跨年月缩放时间轴、键盘精细步进、按关键词/标签/地点过滤和聚合回顾。

## 9. 资料导入、导出与迁移

- [x] 内容导出：记录和媒体写入 `Records`，加密大文件逐个解密到 `Files`。
- [x] 迁移备份：复制可运行 `System`、加密 `Archive` 和恢复所需 `UserData`。
- [x] 大文件密文仓库支持虚拟目录浏览、加密导入、临时打开与按项解密提取。
- [x] 导出前再次确认目标位置；不修改原资料库。
- [x] 旧版纯文本日记导入：识别 `月.日` 分段并转为日记录。
- [x] 导入采用文件选择器和预览确认，不默认扫描私人目录。
- [x] 同日期冲突默认跳过，防止覆盖既有记录。
- [ ] 自动恢复向导、增量备份、导出目录加密、完整性验证 UI。
- [ ] 图片 OCR 辅助导入历史年记；批量资料归档与重复项检测。

## 10. 稳定性、质量与发布

- [x] 主进程禁用 Node 集成，启用 context isolation 和受限 IPC 白名单。
- [x] 严格限制文件读取范围；媒体只允许通过受控协议访问资料库资源。
- [x] 数据服务的日期、路径和记录类型校验。
- [x] 单元测试覆盖日期、格式规范化和旧日记解析核心逻辑。
- [x] 开发运行脚本与 Windows 文件夹启动器构建配置。
- [ ] E2E 自动化、崩溃恢复演练、超大资料库性能基准、签名安装包。
- [ ] 正式发布前隐私/安全审计、备份恢复演练、迁移兼容矩阵。

## 11. 首版验收路径

1. 首次启动创建身份与口令；启用“信任”后重启可从身份页直接进入，取消后密钥框恢复。
2. 编辑今天的正文和标签，等待状态显示“已保存”，重启后内容仍存在。
3. 插入图片并命名标签，确认正文只显示标签且可先小预览再看大图；录音停止并命名后，确认标签上方可直接播放。
4. 创建两类日期标注，确认文字显示在月历日期格内。
5. 通过地点区的“＋”保存地点；从顶部短横柄向下拖拽显露星空并点亮星星，重启后状态仍存在。
6. 进入过去，完成二次验证，拖动统一时轨并验证年刻度与记录日刻度。
7. 在历史页面分别验证“导出内容”的解密目录和“迁移备份”的 System / Archive / UserData 结构。
8. 运行 `npm test`、`npm run pack`，最终运行项目根目录的 `Gobsmacked.exe`。
